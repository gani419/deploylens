# DeployLens privacy policy

Effective: October 26, 2026

DeployLens is a development product for mobile app developers. It inspects APK, AAB and IPA archives and presents technical release-readiness evidence.

## Data handling

DeployLens does not provide user accounts or authentication and does not use an application database. The product does not intentionally collect names, email addresses, phone numbers, advertising identifiers, behavioral analytics or usage profiles. The browser stores only the selected appearance preference.

On a hosted website, a selected build is transmitted to the inspection server in use. It is processed in a private temporary workspace and deleted after completion, failure, cancellation or timeout. A stale-workspace sweep handles data left after an interrupted server process. DeployLens does not use uploaded builds for advertising, user profiling, model training or a permanent build library.

A hosting provider may process ordinary network information such as IP addresses in infrastructure logs. Operators of a public DeployLens service must document their hosting and logging configuration separately.

## Desktop application

The desktop application runs the workspace and inspection service locally through a loopback-only connection. Selected builds are not sent to a DeployLens-operated cloud service unless the user separately chooses a remote service or sharing destination.

## Downloads and sharing

Reports and builds are downloaded, copied or shared only after a user action. Files intentionally saved remain on the selected device or destination. Third-party mail, chat, storage and sharing services apply their own privacy terms.

## Product limits

DeployLens provides static technical checks and guidance. It does not guarantee Google Play or Apple App Store approval. Runtime behavior, legal compliance, store-account standing, privacy disclosures and final release decisions remain the developer's responsibility.

## Questions and support

Use the [DeployLens issue tracker](https://github.com/gani419/deploylens/issues) for product and privacy questions. Do not attach confidential builds, reports, credentials or personal information to a public issue. Security concerns should use the repository's private security reporting channel when available.

Policy effective date: October 26, 2026.
