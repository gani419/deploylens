Locally served variable fonts

DM Sans: body copy, controls, labels and subtitles (100-1000 weight).
Manrope: titles, section headings and prominent numeric values (200-800 weight).

Source: Google Fonts repository
https://github.com/google/fonts/tree/main/ofl/dmsans
https://github.com/google/fonts/tree/main/ofl/manrope

The original font files are unmodified. Corresponding SIL Open Font License
texts are included as DM-Sans-OFL.txt and Manrope-OFL.txt.
The website does not request these fonts from an external CDN at runtime.
