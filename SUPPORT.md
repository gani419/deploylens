# DeployLens support

Use [GitHub Issues](https://github.com/gani419/deploylens/issues) for reproducible product problems, documentation corrections and feature requests.

Include the DeployLens version, operating system, archive type, result section, expected behavior and actual behavior. Remove application identifiers, signing details, internal URLs and other confidential information before posting. Do not upload a private APK, AAB, IPA or full report to a public issue.

For a suspected security vulnerability, use the repository's private security reporting channel when it is enabled. Do not publish exploit details or sensitive build data in a public issue.

DeployLens is development tooling. A report does not replace device testing, official store validation, legal review or a final release decision by the application owner.
